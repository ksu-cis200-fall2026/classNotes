Guesses with duplicate letters.

correct: "enemy"
guess: "geese"
feedback: BYGBB

correct: "glove"
guess: "ledge"
feedback: YBBYG



Algorithm:

used array: booleans (same size as the word)
feedback array: characters (same size as the word)


initially: used is all false, feedback is empty


green feedback: 
    do first, mark "G" in feedback array for any
    guess letter in the correct spot.

    mark the same position in used to be true.


yellow/black feedback:
    loop over guess letters (i)
        if feedback[i] is G, continue (that letter is already done)
        loop over correct letters (j)
            if guess[i] == correct[j] AND used[j] is still false:
                feedback[i] = Y 
                used[j] = true
        if never found a match (feedback[i] isn't a Y):
            feedback[i] = B


used/feedback get recreated with each guess
