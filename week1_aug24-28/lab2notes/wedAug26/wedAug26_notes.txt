Variables.



Data types in Java.

    int - integer, whole number
    double - something with decimal (also whole number)
    String - text, sentences, words
    char - individual character 
    boolean - true/false




Declaring variables.

    type name;


    int age;




Initialize/assign variables.

    name = literal/expression/other variable;

    age = 17;

    age = age + 1; //age is now 18

    age *= 2;  //updates age to 36
    age = age * 2;

    age++;  //age is now 37
    age += 1;
    age = age + 1;




Literals. - specific value
    17 - int
    'a' - char
    "a" - String
    3.45 - double
