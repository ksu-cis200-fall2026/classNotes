Java HashMap. 

What is stored for each item?
(key, value)


keys: must be unique



Want keys to be names, values to be Person objects

HashMap<String, Person> map = new HashMap<String, Person>();


--> add a few people 

//Bob, 20
map.put("Bob", new Person("Bob", 20));
map.put("Alice", new Person("Alice", 30));
map.put("George", new Person("George", 10));
map.put("Bob", new Person("Bob", 22)); //replaces the other Bob


--> how would we find the oldest one?

int oldestAge = 0;
Person oldestPerson = null;
for (String name : map.keySet()) {
    Person cur = map.get(name);
    if (cur.getAge() >= oldestAge) {
        oldestAge = cur.getAge();
        oldestPerson = cur;
    }
}
//oldestPerson IS the oldest
