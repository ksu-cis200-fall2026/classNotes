--> how would we find the oldest one?

int age = 0;
Person oldest = null;
for (String n : map.keySet()) {
    Person p = map.get(n);
    if (p.getAge() > age) {
        age = p.getAge();
        oldest = p;
    }
}
System.out.println(oldest);

What is the file format?

What do we do when we see a name: score?


reading the input file, have current name and score
    have I seen that student before?
    use containsKey to see if name is in HashMap
    if it is:
        use get to get the existing Student with that name
        call addScore on that Student to add the new score
    if name isn't already in HashMap:
        create a new Student object with that name
        call addScore on your new Student to add that score
        call put to add the new Student to your HashMap
