Example, print this pattern:

5

3 4 5
2 3 4 5
1 2 3 4 5

what's different on each? 

loop through rows (loop through the starting number)
    loop through columns

for (int i = 5; i >= 1; i--) {
    //i is the starting number of the current row 
    for (int j = i; j <= 5; j++) {
        System.out.printf("%d ", j);
    }
    System.out.println();
}
