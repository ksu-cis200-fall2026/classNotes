Lab 13.

vectors in 3D have an x-coordinate, y-coordinate, z-coordinate:
    (x,y,z)

Adding vectors:
    (1,2,3) + (4,5,6) = (5,7,9)

Vector magnitude (length):
    magnitude of (x,y,z): sqrt(x^2 + y^2 + z^2)
    magnitude of (1,2,3): sqrt(1 + 4 + 9) = sqrt(10)

Normalize a vector:
    UPDATE each coordinate so the length is 1
    example: normalize (1,2,3)
        magnitude of (1,2,3) = sqrt(1^2 + 2^2 + 3^2) = 4.12
    now divide each coordinate by 4.12:
        (1/4.12, 2/4.12, 3/4.12) = (0.24, 0.49, 0.73)
    (0.24, 0.49, 0.73) is the normalized vector


In Vector3:

- magnitude (already written)
    - takes a vector (array of doubles)
    - returns the length of the vector (a double)
- addVectors
    - takes two vectors (as arrays of doubles)
    - add/returns (new) sum of parameter vectors
- printVector
    - takes a vector (array of doubles)
    - prints it in the format "(1.23, 4.56, 7.89)"
- normalize
    - takes a vector (as an array of doubles)
    - MODIFIES the parameter vector to be normalized
    (divide each parameter by the length)
    (need to SAVE the original length before changing the vector)
