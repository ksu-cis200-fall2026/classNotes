How to print "hello" 5 times?

//how many times I've printed hello so far
int count = 0;

//while I haven't printed hello 5 times
while (count < 5) {
    System.out.println("hello");

    //I've printed hello one more time
    count++;
}

    System.out.println(num);
    num++;

overall: total miles / (total gallons of gas)

--> what are we doing first?
--> what are we repeating?
--> what do we need to keep track of as we loop?

Pseudocode:

user input:
    initialMileage
    readings

curReading = 0
previousMileage = initialMileage
totalGallons = 0

while curReading < readings
    curReading++
    curMileage = user input
    curGallons = user input
    economy = (curMileage-previousMileage)/curGallons
    previousMileage = curMileage
    totalGallons += curGallons

overall: (previousMileage-initialMileage) / (total gallons of gas)
